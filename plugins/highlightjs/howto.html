highlight.js - coloration de code

Colore automatiquement les blocs de code du site (licence BSD-3) : PHP, HTML, CSS, JavaScript, SQL, Bash et une trentaine d'autres langages. Thème « GitHub ».

Blocs concernés : <pre><code>. Le langage est détecté seul, ou précisé :

<pre><code class="language-php"><?php echo 'Bonjour'; ?></code></pre>

Thème sombre : remplacer styles/github.min.css par styles/github-dark.min.css dans inc/functions.php, ou surcharger les couleurs dans votre CSS.
